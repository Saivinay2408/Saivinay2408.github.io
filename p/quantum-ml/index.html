How it works

Quantum-Enhanced 3D Scene Reconstruction

Production-ready implementation of Quantum Neural Radiance Fields (QNeRF) and Quantum Visual Fields (QVF)

🌟 Overview

State-of-the-art quantum machine learning system for 3D scene reconstruction featuring: - Exponential Hilbert space expressivity via parameterized quantum circuits - Comparable parameter count to classical NeRF with richer representational capacity - +2 dB PSNR improvement reported in literature (Blender dataset benchmarks)

🚀 Quick Start

Installation

cd QC
pip install -r configs/requirements.txt

Train a Model

python src/train.py

Run Benchmarks

python tests/quick_benchmark.py

Interactive Demo

python src/demo.py
