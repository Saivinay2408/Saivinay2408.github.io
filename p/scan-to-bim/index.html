How it works

Differentiable Scan-to-BIM: Automating Construction Digital Twins

Abstract

This project presents an end-to-end framework for automating the generation of Building Information Models (BIM) from unstructured construction site video. Addressing the industry-wide challenge of manual inspection, we propose a Universal Scan-to-BIM Pipeline that robustly processes 360-degree and standard video inputs, performs semantic understanding via PointNet++, and utilizes differentiable optimization to fit geometric primitives. The system delivers "Professor-Ready" artifacts, including Digital Twins, Civil Engineering Blueprints, and Automated Inspection Reports, effectively bridging the gap between raw sensor data and actionable construction insights.

1. Methodology: The Intelligent Pipeline

The framework operates on a "Capture-Perceive-Optimize" paradigm, designed for modularity and failure resilience.

graph TD
    A[Input: Video Stream] -->|Auto-Detection| B{Source Type?}
    B -->|360 Equirectangular| C[Unwarping Engine]
    B -->|Standard Perspective| D[Direct Extraction]
    C --> E[Multi-View Frames]
    D --> E
    E -->|Structure-from-Motion| F[Sparse Point Cloud .ply]
    F -->|Deep Learning| G[Semantic Segmentation]
    G -->|Differentiable Optimization| H[BIM Primitives]
    H -->|Analysis| I[Insight Report]
    H -->|Rendering| J[Digital Twin]

Phase 1: Universal Perception

The system employs an adaptive ingestion engine (src/video_utils.py) that handles diverse input sources. For 360-degree inputs, it performs real-time equirectangular-to-perspective projection, simulating four virtual cameras (Front, Back, Left, Right) to maximize photogrammetric overlap. For standard inputs, it optimizes frame extraction rates for reconstruction stability.

Phase 2: Sparse Reconstruction

We utilize COLMAP (Structure-from-Motion) to recover 3D geometry from 2D frames. The robust ColmapRunner (src/colmap_utils.py) enforces strict validation, ensuring that only high-quality sparse clouds proceed to the semantic stage. We implemented a custom bridge to convert COLMAP's internal binary format to standard .ply for deep learning ingestion.

Phase 3: Semantic Understanding

The core intelligence lies in the PointNet++ architecture (src/semantic.py). This deep neural network processes the raw 3D point cloud to classify structural elements (Floor, Wall, Ceiling). * Architecture: Hierarchical Feature Learning (Set Abstraction $\to$ Feature Propagation). * Innovation: Corrected PyTorch tensor logic for consistent downsampling/upsampling across varying point densities.

Phase 4: Differentiable Optimization

Using the semantic labels, we apply a differentiable fitting loss to align AS-DESIGNED primitives (cuboids) with AS-BUILT points via Stochastic Gradient Descent (SGD) (src/optimization.py).

6. Installation & Reproduction

Prerequisites

  • System: macOS / Linux
  • Dependencies: colmap (installed via Homebrew/apt), torch, open3d, numpy, opencv-python.

Steps

  1. Install COLMAP: bash brew install colmap
  2. Install Python Libs: bash pip install torch torchvision open3d numpy opencv-python matplotlib
  3. Run the Pipeline: bash export OMP_NUM_THREADS=1 # Prevent macOS OpenMP conflict python3 main.py --video "data/your_video.mp4"
