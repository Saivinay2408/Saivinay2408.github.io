How it works

🛡️ OracleGuard — Self-Monitoring Credit Risk System

A production-grade credit risk monitoring pipeline that detects model drift, automates champion/challenger retraining, and catches LLM hallucinations in loan rejection explanations — all built on the Databricks Lakehouse.

💡 Key Innovations

1. Impact-Weighted PSI

Standard PSI treats all features equally. We weight each feature's PSI by its SHAP importance, so drift in a top-predictor triggers retraining — but drift in a negligible feature doesn't cause false alarms.

Impact-Weighted PSI = PSI_feature × SHAP_importance_feature

2. Deterministic Regulation Checking

Instead of using an LLM to validate LLM-cited regulations (circular!), we match citations against a curated ground truth corpus of 25 real RBI/SEBI circulars. This is provably correct — no hallucination can survive an exact-match check.

3. 4-Signal Composite LLM Scoring

Rather than a binary "hallucinated or not" label, each loan rejection explanation is scored on 4 independent dimensions:

Signal Weight Type What It Catches
Factual Grounding 30% Deterministic Does it reference actual applicant data?
Regulation Validity 30% Ground Truth Match Do cited RBI circulars actually exist?
Logical Coherence 20% Pattern-Based Does reasoning follow from evidence?
Completeness 20% Checklist Are all required components present?

4. Triple-Gate Promotion

A Challenger model must pass all three gates to be promoted: - AUC Gate: Challenger AUC ≥ Champion AUC - Precision Gate: Challenger Precision ≥ 95% of Champion Precision - Recall Gate: Challenger Recall ≥ Champion Recall

This prevents "accuracy theater" where a model improves AUC but collapses on precision (= more bad loans approved).
