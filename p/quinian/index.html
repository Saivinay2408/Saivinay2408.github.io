What this is

The first end-to-end computational instantiation of Carey's Quinian bootstrapping theory within a neural program-synthesis architecture. A typed domain-specific language is initialized with primitives organized into Spelke's core-knowledge systems (OBJECTS, FORMS, NUMBER, with AGENTS, PLACES, and PERSONS extensions), and a DreamCoder-style wake-sleep loop with Stitch anti-unification runs over ARC-AGI and purpose-built cross-system benchmarks. Every abstraction the compressor discovers carries cross-system provenance, so the Carey signature — a placeholder-bearing combinator spanning incommensurable systems — is directly measurable.

Disclosed configuration flags

All search-geometry and compression mechanisms introduced after the canonical run are config-gated and OFF by default; default settings reproduce the original results bit-identically (checked by a cross-engine differential test over all flag combinations):

Flag What it does Used by
--enum-fair-caps / --enum-cap-scale Per-root fair shares of enumeration buckets §4.10+
--enum-fair-args Per-first-argument fair shares within a root's share §4.11+
--enum-dep-first Input-dependent candidates before constants §4.11+
--stitch-canonical Compression as a pure function of the solved-program set (order-invariant, deployability-first ranking) §4.12+
--rust Rust enumeration engine (parity-verified; every solution re-verified in Python) §4.10+

Method (one paragraph)

WAKE: a recognition-guided AST solver and a type-directed, cost-bounded enumerator search for programs that solve each task. ABSTRACTION SLEEP: the corpus of solving programs is compressed by Stitch anti-unification; abstractions that reduce total description length (ΔL = size×(count−1)−count−n_holes > 0) are registered as typed, callable, cost-1 primitives, with exact cross-cycle deduplication. DREAMING SLEEP: a dream generator (pipeline / cross-system / PCFG modes) trains a recognition network. Each cycle's abstractions become first-class parts for the next cycle's search — Carey's staircase, computationally.
